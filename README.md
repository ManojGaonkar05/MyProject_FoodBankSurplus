## Repository structure

Coursework is organized into seven top-level folders named `LAB 1` through `LAB 7`.

| Folder | Contents |
|---|---|
| [LAB 1](LAB%201/) | Requirements engineering and use cases (`Requirements/`), Software Requirements Specification and Work Breakdown Structure (`SRS_and_WBS/`) |
| [LAB 2](LAB%202/) | GitHub/Jira project-management evidence: Kanban, Scrum, bug tracking and the available repository screenshot |
| [LAB 3](LAB%203/) | System architecture diagram in PNG and SVG formats |
| [LAB 4](LAB%204/) | GitHub Copilot prompt/output screenshots and Word Scramble bug-fix/retest documentation, grouped in separate subfolders |
| [LAB 5](LAB%205/) | Point-of-sale code, static-analysis issue/reflection notes, and before/after Pylint, Bandit and Flake8 reports |
| [LAB 6](LAB%206/) | Food-donation workflow, code and branch coverage, and the UI screenshot (`screenshots/ui.png`) |
| [LAB 7](LAB%207/) | Food-donation input processor and Hypothesis-based property tests |

The Lab 2 README lists the evidence included and the screenshots that are not present. Lab-specific run instructions are in the corresponding lab README files.
